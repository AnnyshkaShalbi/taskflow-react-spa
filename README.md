# TaskFlow

SPA-трекер задач и привычек для небольших команд: канбан-доски с общим доступом, комментарии к задачам, трекер привычек и графики прогресса. Полностью работает в браузере: API имитируется через MSW, поэтому проект можно открыть и попробовать без бэкенда.

## ✨ Возможности

- 📋 **Канбан-доска** с drag-and-drop, продуманная для мобильных устройств
- 👥 **Общие доски**: приглашение участников, переключение между досками
- 💬 **Подробный просмотр задачи**: исполнитель, срок, комментарии участников
- 🔁 **Трекер привычек** со стриками и недельным прогрессом
- 📊 **Дашборд**: статистика и график активности за неделю
- 📱 **Адаптивная вёрстка**: телефон, планшет, десктоп
- 🌗 Светлая и тёмная темы

## 🔑 Демо-доступ

На странице входа можно войти в один клик под одним из демо-пользователей или через форму: `anna@taskflow.dev` / `password123`.

💡 Пользователи работают на общих досках: напишите комментарий к задаче под одним из них, а затем войдите под другим, чтобы увидеть совместную работу.

## 🧩 Ключевые решения

### Мобильная канбан-доска

Перетаскивать карточки на телефоне неудобно, поэтому drag-and-drop там остаётся дополнительным инструментом, а у каждого действия есть альтернатива без него.

| Проблема | Решение |
| --- | --- |
| Три колонки не помещаются на экране | Горизонтальная лента со scroll-snap, край следующей колонки подсказывает, что ленту можно листать |
| Свайп по карточке перетаскивал её вместо прокрутки | Отдельные сенсоры для мыши и касаний: на тачскрине drag начинается только по долгому нажатию |
| Перетаскивание неочевидно | Меню «Переместить в…» на карточке: статус меняется в два тапа |
| Непонятно, где ты на доске | Закреплённые табы со счётчиками, синхронизированные с прокруткой ленты |
| Долго тянуть карточку в дальнюю колонку | Карточку можно бросить прямо на таб. Для закреплённых табов написана своя логика определения цели |
| Непонятно, что карточка «взята» | Тактильный отклик (Vibration API) и визуальный «подъём» карточки |

### Оптимистичный UI

Смена статуса, перетаскивание, удаление задач и добавление комментариев применяются мгновенно, до ответа сервера. Если запрос не прошёл, состояние откатывается (TanStack Query, `onMutate` / `onError`). Введённый текст комментария при этом не теряется.

### Демо-режим без бэкенда

MSW работает и в production-сборке, поэтому приложение разворачивается на любом статическом хостинге. Режим задаётся флагом `VITE_DEMO_MODE` и превращается в константу времени сборки. Если собрать проект без демо-режима, сборщик полностью вырезает моки и демо-аккаунты из бандла, и это проверено на собранных файлах. Демо-аккаунты хранятся в одном месте, которое используют и мок-сервер, и страница входа.

### Права доступа на стороне API

Мок-сервер ведёт себя как настоящий бэкенд, а интерфейс только скрывает недоступные действия:

- Пользователь определяется по токену, а не по телу запроса. Запрос без токена получает `401`.
- Задачи и комментарии видят только участники доски. Чужие данные отвечают `404`, чтобы не раскрывать, что они существуют.
- Управлять доской и её участниками может только владелец, остальные получают `403`. Исполнителем назначается только участник доски.
- Удалить можно только свой комментарий. Удаление доски или задачи каскадно удаляет связанные данные.

### Доступность

Карточки открываются с клавиатуры (stretched button), у интерактивных элементов есть подписи для скринридеров. На тач-устройствах увеличены области нажатия, а скрытые по наведению действия всегда видны (`pointer-coarse` / `pointer-fine`).

## 🏗 Архитектура

Проект построен по методологии **[Feature-Sliced Design](https://feature-sliced.design/)**.

```
src/
  app/        # точка входа, провайдеры, роутер, глобальные стили
  pages/      # страницы под маршруты
  widgets/    # самостоятельные блоки интерфейса (KanbanBoard, TaskList, Header)
  features/   # пользовательские сценарии (create-task, add-comment, manage-members)
  entities/   # бизнес-сущности (task, comment, board, user, habit)
  shared/     # переиспользуемое: ui, lib, api, config
  mocks/      # MSW: обработчики и стартовые данные
```

Слой импортирует только из слоёв ниже себя, внутри слоя — только через public API (`index.ts`).

## 🚀 Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

```bash
npm run build      # production-сборка (демо-режим включён в .env.production)
npm run preview    # просмотр сборки локально
npm run lint       # проверка ESLint
npm run format     # форматирование Prettier
```

Данные демо-режима хранятся в `localStorage` браузера. Чтобы вернуть стартовые данные, очистите `localStorage` сайта.
